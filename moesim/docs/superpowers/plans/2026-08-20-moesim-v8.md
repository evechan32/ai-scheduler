# moesim v8 — KV 分层模拟 + 联合调度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

### Task 52: KVJointPolicy（高压 CPU 化 + 暂停预取 + evict）

**Files:**
- Create: `moesim/scheduler/policies/kv_joint.py`
- Test: `tests/scheduler/test_kv_joint_policy.py` (new)

**Interfaces:**
- `KVJointPolicy(OverlapAwarePolicy)`：`__init__(..., kv_pressure_threshold=0.8)`
- `decide`：
  - `pressure > threshold` → 非驻留专家 execute_cpu（不 load/prefetch 进 GPU）；
    `pressure >= 1.0` → evict 最冷非请求 KV；跳过 prefetch。
  - 否则 → 正常 v6 EFT + prefetch。
- 测试：高压 CPU 化、高压无 prefetch、高压 evict、低压正常 EFT。
